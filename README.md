# TODO

依存ライブラリなしの、シンプルな TODO アプリです。

公開版: https://todo-eight-rho-79.vercel.app/ （`master` にプッシュすると自動デプロイ）

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。

- 入力欄にやることを書いて Enter（期限は任意）
- チェックボックスで完了 / 未完了を切り替え
- タイトルをダブルクリックで編集（Enter で確定、Esc で取消、空にすると削除）
- 「すべて」「未完了」「完了済み」で絞り込み（URL の `#/active` などでも指定可）
- 期限切れは赤、今日が期限のものは青で表示

データはブラウザの `localStorage`（キー `todo-app.v1`）に保存されます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | スタイル（ダークモード対応） |
| `app.js` | 状態管理・描画・イベント処理 |
